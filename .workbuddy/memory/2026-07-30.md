# 2026-07-30

## 修复：本地音乐播放器无法播放（HM_Player / Lumio Music）
- **根因**：`AudioRendererController.loadAndPlay()` 只设置 `avPlayer.fdSrc`（→initialized 状态），但从未调用 `prepare()`，也没有任何地方在 prepared 后触发 `play()`。AVPlayer 状态机要求 idle→initialized→prepared→playing，缺中间两步导致永远停在 initialized，UI 第二次点击 `start()` 时 `play()` 在非法状态被拒绝 → 无声。
- **修复（官方推荐模式）**：在 `stateChange` 回调中驱动状态机 —— `initialized`→`prepare()`，`prepared`→`start()`(即 play())。同时修复文件句柄泄漏：新增 `curFile` 字段，切歌/释放时 `closeSync`。
- **注意**：工程存在两份内容基本一致的 `AudioRendererController.ets`（entry 与 MediaService 模块），均已同步修复；entry 副本为 UI 实际引用方。
- **改名**：app 显示名 HM_Player/HM_Music → **Lumio Music**。改了 `AppScope/.../string.json` 的 `app_name`，以及 `entry/.../string.json` 的 `EntryAbility_label` 与 `page_show`。
- 运行 harmonyos-reviewer 扫描+审查：0 ERROR / 0 WARNING（2 个无关 INFO：componentSnapshot.get 上下文待人工确认）。
