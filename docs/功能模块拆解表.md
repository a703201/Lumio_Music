## 三、跨模块依赖与接口边界

| 上游 | 下游 | 交互方式 |
|---|---|---|
| 页面（LocalLibrary/Mine） | AudioRendererController | `playFromList(list, index)` 点歌即播 |
| AudioRendererController | AVSessionController | `bindAudioRendererController` + `setAVMetadata/setPlayState/setProgressState` |
| AVSessionController | 系统（锁屏/控制中心的媒体卡） | `AVSession` 事件回调 |
| AVSessionController | FormAbility/WidgetCard | `formProvider.updateForm` / `remoteControl` |
| EntryAbility | AVSessionController | `handleControlWant` 桌面卡片回控指令 |
| MusicStore | AudioRendererController/AppStorage | `songList` 双写；`reconcileWithLibrary` 对齐 |
| Playlists / PlaylistDetail | MusicStore | 歌单 CRUD 全部经 `MusicStore`，页面只持有歌单 id 不缓存对象副本 |
| PlaylistDetail | AudioRendererController | `setQueue(歌单曲目, index, true)`——把歌单整体设为播放队列，与本地库全量队列隔离 |
| AVSessionController | MusicStore | 收藏读写唯一入口 `toggleFavorite/isFavorite`（按 song.id） |
| CoverCache | 各列表页 / 播放页 | `getMark()/getLabel()` + `coverRefreshToken` 刷新 |
| ThemeManager | 全部页面 | `@StorageProp('isDark')` + 色令牌 |
