## 二、详细拆解

### A. 音频播放
| 编号 | 功能 | 涉及 API/Kit | 代表文件 |
|------|------|------------|---------|
| A-01 | 播放控制 | media.AVPlayer | `AudioRendererController.ets` |
| A-02 | 进度管理 | timeUpdate / durationUpdate | `AudioRendererController.ets` |
| A-03 | 播放模式 | 列表/单曲/随机 | `MusicStore.ets` |

### B. 音乐库
| B-01 | 导入音乐 | picker.DocumentViewPicker + fs | `LocalLibrary.ets` |
| B-02 | 搜索过滤 | 字符串匹配 | `LocalLibrary.ets` |
| B-03 | 空状态+错误态 | animateTo / LoadingProgress | `LocalLibrary.ets` |

### F. 播放器页面
| F-01 | 封面大图 | geometryTransition 共享元素 | `PlayerInfoComponent.ets` |
| F-02 | 歌词显示 | Canvas | `LrcView.ets` |
| F-03 | 播放控制 | animateTo | `ControlAreaComponent.ets` |
| F-04 | 歌曲信息 | 标题/歌手/专辑 | `MusicInfoComponent.ets` |
| F-05 | 顶部区域 | 返回/分享 | `TopAreaComponent.ets` |

### G. 歌词系统
| G-01 | LRC 解析 | 正则+时间戳分组+CJK语种判断 | `LrcUtils.ets` |
| G-02 | KRC 解析 | 正则+逐字时间轴 | `LrcUtils.ets` |

### H. 音频元数据
| H-01 | MediaKit 路径 | AVMetadataExtractor | `AudioMeta.ets` |
| H-02 | C++ NAPI 兜底 | FLAC/MP3/MP4 原生解析 | `audio_metadata.cpp` |

### J. 封面系统
| J-01 | 封面缓存 | Map 缓存 + 负缓存 + 在途去重 | `CoverCache.ets` |
| J-02 | 响应式封面组件 | coverRefreshToken + src 双信号 | `CoverImageView.ets` |

### M. 设置
| M-01 | 设置主页 | 分类入口（播放/显示/关于） | `Settings.ets` |
| M-02 | 设置子页 | 自动下一首/播放模式/主题/锁屏 | `SettingsCategory.ets` |

### O. 自建歌单
| O-01 | 歌单列表 | 新建/重命名/删除/同名校验 | `Playlists.ets` |
| O-02 | 歌单详情 | 播放全部/添加/移出/拖拽排序 | `PlaylistDetail.ets` |
| O-03 | 数据层 | CRUD + 持久化 | `MusicStore.ets` |
| O-04 | 导航入口 | route_map 注册 + id 参数 | `route_map.json` |

### P. 歌曲操作
| P-01 | 长按选项栏 | bindContextMenu 统一渲染 | 5 个页面 |
| P-02 | 详情面板 | bindSheet MEDIUM/LARGE | `SongDetailSheet.ets` |
| P-03 | 添加到歌单 | bindSheet Medium | `AddToPlaylistSheet.ets` |
| P-04 | 年代解析 | C++→NAPI→ArkTS 全链路 | `AudioMeta.ets` |

### R. C++ 原生后端
| R-01 | FLAC 解析 | VORBIS_COMMENT + STREAMINFO | `audio_metadata.cpp` |
| R-02 | MP3 解析 | ID3v2 + MPEG 帧头 + Xing/Info VBR | `audio_metadata.cpp` |
| R-03 | MP4 解析 | mvhd v0/v1 + ilst + largesize | `audio_metadata.cpp` |

## 三、跨模块依赖

| 上游模块 | 下游模块 | 交互方式 |
|---------|---------|---------|
| MusicStore | 所有页面 | 单例访问 songs/playlists/favorites |
| AudioRendererController | PlayerPage / Layout | AppStorage + 单例 |
| CoverCache | 各列表页 / 播放页 / 迷你播放器 | getMark()/getLabel() + coverRefreshToken |
| AVSessionController | AudioRendererController | 双向绑定媒体会话 |
| AudioMetaReader | MusicStore / SongDetailSheet | taskpool.execute 异步读取 |
