## 二、关于「产品形态」的说明（必读）

课程明确要求最终作业**不一定是 Web，也可以是 App 或小程序**。Lumio Music 正是 **HarmonyOS 原生 App**（ArkTS + ArkUI + C++ NAPI），运行于鸿蒙手机系统，**完全符合课程的「App 形式」交付要求**，无需提供 Web 链接。

评审时可从以下三个层面呈现这个 App：

1. **可安装运行产物（核心交付）**
   - 签名 HAP：`entry/build/default/outputs/default/entry-default-signed.hap`，开发者用 DevEco Studio + `bash build_hap.sh` 可复现构建。
2. **真机演示视频（直观展示）**
   - 在线播放：`README.md` 内嵌 `<video src="https://raw.githubusercontent.com/a703201/Lumio_Music/main/Video/Demo.mp4">`
   - 本地下载：`Video/Demo.mp4`（约 50MB）
3. **开源仓库（源码可查）**
   - GitHub：`https://github.com/a703201/Lumio_Music`
   - GitCode：`git@gitcode.com:a703201/HM_Player.git`

> 推荐提交话术：
> 「本项目为 HarmonyOS 原生 App（课程允许的 App 形式交付），已产出可安装签名 HAP、真机演示视频与完整开源仓库，完整交付物见本清单。」
