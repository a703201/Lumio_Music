## 二、关于「线上产品链接」的说明（必读）

课程表第 6 课原要求提供**「可访问的线上产品链接」**。Lumio Music 是 **HarmonyOS 原生应用**（ArkTS + ArkUI + C++ NAPI），运行环境为鸿蒙手机系统，**不具备 Web 服务端，因此无法像网页一样提供 `https://...` 在线访问链接**。

提交时建议直接说明这一点，并给出以下等效替代项（均已现成）：

1. **源码仓库（等效「线上可见性」）**
   - GitHub：`https://github.com/a703201/Lumio_Music`
   - GitCode：`git@gitcode.com:a703201/HM_Player.git`
2. **真机演示视频（等效「线上体验」）**
   - 在线播放：`README.md` 内嵌 `<video src="https://raw.githubusercontent.com/a703201/Lumio_Music/main/Video/Demo.mp4">`
   - 本地下载：`Video/Demo.mp4`（约 50MB）
3. **可构建产物（等效「可运行示例」）**
   - 签名 HAP：`entry-default-signed.hap`，开发者用 DevEco Studio + `bash build_hap.sh` 可复现

> 推荐提交话术：
> 「本项目为 HarmonyOS 原生应用（HAP），非 Web 项目，因此以『GitHub/GitCode 仓库源码 + 真机演示视频 + 可构建签名 HAP』替代线上访问链接，完整交付物见本清单。」
